# Smoke test — 5 minutos después de instalar un APK

Si algo de esto falla, **no sigas probando**: el APK está roto. Anota cuál y avisa.

- [ ] La app abre sin cerrarse sola y muestra **Inicio**.
- [ ] Cambia entre **Inicio · Tareas · Gastos · Ajustes** sin errores.
- [ ] **Tareas** carga tus tareas reales (hay red y la conexión a Neon sirve).
- [ ] Crear una tarea de prueba con fecha *Hoy* → aparece en Inicio y en Tareas › Hoy.
- [ ] **▶ Empezar** en esa tarea → abre el pomodoro y la cuenta baja. Pausar y Seguir funcionan.
- [ ] Salir de la app con el pomodoro corriendo → la notificación fija muestra el tiempo.
- [ ] Cerrar el pomodoro y marcar la tarea como **Hecha** → pasa a *Terminadas hoy* (tachada).
- [ ] Marcar y desmarcar un hábito de hoy → cambia el ✓ y la racha.
- [ ] **Gastos** muestra los movimientos de hoy y el total.
- [ ] Ajustes abre y el tema claro/oscuro cambia.

Al terminar, borra la tarea de prueba (o márcala hecha) para no ensuciar la lista.
